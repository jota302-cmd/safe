# Link Shield 🛡️

**Link Shield** (Safe) es una micro-utilidad de seguridad orientada a revelar el destino real de enlaces sospechosos ocultos bajo acortadores o redirecciones.

## 🚀 Características

- **Desofuscación de URLs**: Resuelve enlaces acortados (bit.ly, t.co, etc.) de forma segura.
- **Zero-Execution**: Muestra el destino sin ejecutar scripts ni descargar contenido del sitio objetivo.
- **Protección Phishing**: Evita redirecciones ocultas y ataques de un clic.
- **100% Privado**: La consulta no queda registrada en bases de datos internas.

## 🛠️ Especificaciones Técnicas

- **Stack**: HTML5, Tailwind CSS, Vanilla JavaScript.
- **Arquitectura**: Protocolo de aislamiento.
- **Despliegue**: Subdominio Vercel (`safe.optimicrotools.com`).
